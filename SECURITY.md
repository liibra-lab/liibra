# Security Policy

Liibra is an independent project for open access to Brazilian legal information.
Please report suspected security issues privately instead of opening a public issue.

## Reporting a vulnerability

Email: sir.space.octopus@gmail.com

Include as much detail as possible:

- Affected URL, route, file, or dependency.
- Steps to reproduce.
- Expected impact.
- Whether credentials, user data, deployment access, or legal-source integrity may be affected.
- Suggested fix, if available.

## Scope

Security reports are in scope when they affect:

- The public Liibra website.
- The `liibra-lab/liibra` repository.
- Cloudflare Workers deployment configuration.
- GitHub Actions workflows.
- Dependency supply chain integrity.
- External legal data ingestion or source attribution integrity.

Reports are out of scope when they require:

- Denial-of-service testing.
- Social engineering.
- Physical attacks.
- Attempts to access accounts, tokens, or systems that you do not own.

## Disclosure

Do not publicly disclose a vulnerability until it has been reviewed and remediated.
